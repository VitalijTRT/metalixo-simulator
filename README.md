# Metalixo Simulator

Браузерный 3D-симулятор жизни мастера-листогибщика Лёни в небольшом цехе в Латвии:
пресс HACO, заказы по реальным чертежам, Эгил, Виталя, Карлис и дед Кестис,
«Матовая», хрен, огурцы и магнитофон «тройка» с онлайн-радио.

**Играть:** https://vitalijtrt.github.io/metalixo-simulator/

- Компьютер: WASD — ходьба, мышь — обзор, E — действие, F — глоток, Tab — инвентарь, Esc — меню.
- Телефон: левый палец — ходьба, правый — обзор, тап по предмету или кнопка E — действие, ⛶ — весь экран.
  На iPhone: «Поделиться» → «На экран „Домой“» — игра откроется без строки браузера.

Вся игра — один файл `index.html`, работает и офлайн.
